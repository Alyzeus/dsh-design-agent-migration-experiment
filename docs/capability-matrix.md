## 对结论有影响的能力

| 能力 | DSH 报告内容 | 不得推导的结论 | 补验材料 |
|---|---|---|---|
| Art Director | 两方向、五维差异、建议与路由，人工选择，系统建议曾被否 | 自主导演、质量增益 | 原 Brief、两方案、选择记录、实际布局；受控有/无导演对照 |
| Qwen API + ComfyUI | Qwen 审查和卡片实调；ComfyUI 历史生图；另一生图 API 未接 | 已有双生图后端、可按质量/代价路由 | 脱敏接口契约、请求结果、能力表、同题对照 |
| Layout Planner | 合同、预检、字体栈可用；行距/主体保护区未实现 | JSON 中的字段都已渲染 | 合同、负向用例、渲染图与实际墨迹测量 |
| PS | 报告最新试跑 14 层、12 文字层；单稿 36–67 秒；重开回读 | 精确对齐、印刷交付全部通过 | PSD、预览、重开回读和字号/字距/锚点对比 |
| Critique | 10 次外部视觉审查；一次自评 83.4、独立评审 69.0；9 类错误注入被捕获 | 审查全覆盖、统计显著优于自查 | 每次输入、输出、图像版本绑定与同一标准 |
| Design Loop | 七轮评分 76→86；四轮问题数 6→4；有拒绝误判 | 质量必然提升、评分曲线就是用户接受 | 每轮版本、变更、目标收益及非目标偏移 |
| 自动回滚 | dry-run 权限错误；无真实演练，只有手工回退 | 回滚机制可用 | 可写测试项目上完成真实恢复，核对主版本及文件 |
| Style Kit | 158 图/155 可参考、158 卡、46 招，检索与 style_refs 引用 | 招式有效、跨题材迁移通过 | 卡片来源/适用/反例；新题材受控比较 |
| 长期记忆 | 状态可存，恢复、封包不完整 | 跨会话无损接续 | 新会话仅按保存文件恢复，核验完整 Brief 与选定稿 |
| 工程串联 | 合同至 PS/闸门/审查有路径，无单一入口 | 无人值守完整交付 | 真实素材、审查通过与人工签收共同证据 |
