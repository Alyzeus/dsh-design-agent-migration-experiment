# 系统边界与迁移对象

## 迁移的内容

迁移对象是设计决策与执行的工作流：意图拆解、参考依据、方向提案、布局合同、后端选择、制作、审查、返工、止损、回退、交付和接续。这里没有证据证明完整模型能力、工具权限或素材授权可以随文档一起迁移。

| 层 | GPT/Codex 源端 | DSH 目标端（据报告） | 验证边界 |
|---|---|---|---|
| 导演 | GPT 负责方向、规划和版本裁决 | DeepSeek 主控；Art Director 2.0 | 目标端一次提案与路由，无自主裁决/重构实例 |
| 生图 | 宿主 OpenAI 原生图像工具 | 目标保留 Qwen API / ComfyUI 选择 | API 生图未落地；ComfyUI 只有历史验证，报告时停机 |
| 顾问/审查 | 当前 GPT 自查，可按实际能力另行冷读 | Qwen 视觉审查与卡片拆解 | 不把视觉审查接口当成生图接口或独立人类盲评 |
| 布局 | 本机技能有布局规划和确定性渲染说明 | Layout Planner → layout.json → 校验 | 报告合同已用；行距、保护区缺失，回读不完整 |
| 排版 | 原会话要求无 PS；本机技能不接桌面修图 | PS → 可编辑 PSD + PNG | 报告称可用；本次未打开源文件 |
| 记忆 | Brief、状态文件、版本、经验卡等规则 | 状态保存、检查点和检索 | 保存、恢复、有效复用分别验收 |

“Qwen API + ComfyUI 双后端选择”是保留的目标设计。现有摘要把未接入的一路写作第三方生图 API，未给具体 Qwen 生图接口和模型证明；因此不替它补出 API 地址、模型、费用或运行结果。

## 已提供与已运行

本轮要求保留 PS、Layout Planner 已提供/待核实状态；可取得的摘要进一步报告了局部运行结果。这支持“目标端报告已有模块和部分实跑”，仍不足以确认交付包完整、当前环境可用、所有合同字段落实或本次复验通过。

报告的主干可表示为：

```text
需求冻结 → 导演提案/人工选择 → 布局合同 → 校验 → PS → PSD/PNG → 闸门 → 外部审查 → 人工签收
                                     ↑
                       真实素材依赖：Qwen API / ComfyUI（双路未达成）
```

这是对报告结构的说明，不是本次执行轨迹。报告明确说：没有一单同时满足真实素材、评审通过和人工签收；没有单一编排入口。
